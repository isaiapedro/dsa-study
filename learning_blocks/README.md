# Course and interactive examples

Start at [the course contents](../CURRICULUM.md). The numbered Markdown files contain the lessons. course.json records their order and textbook chapter references. The local site builds a contents page and a separate readable page for every module.

blocks.json holds nine short interactive examples connected to the course. Each includes a worked trace, a step to complete, independent practice, and feedback. Their source fields retain the learning-design checks; the page uses simple study language.

These are original authored lessons. External textbooks and LeetCode remain references, with no copied chapters, statements, or solutions. Personal answers and progress do not belong in this directory.

The course uses headings, paragraphs, HTTPS links, and inline code. The renderer escapes source text and does not accept raw HTML, scripts, or external embeds. Learning prompts drafted with assistance retain the existing review-required status; automated checks are not a human pedagogical review.
