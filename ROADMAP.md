# Vision

Provide a durable local study library that builds DSA fundamentals,
interview-ready problem solving, and transferable professional skills.

The detailed work is grouped by Research, Media Assets, Code Competition, and
Infrastructure in [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

## Prototype

- Public catalog sync, canonical topic registry, static site, and Python solution scaffolds.

## MVP

- Completed: a course-first reader with 20 original textbook-style modules,
  full chapter-topic mapping for both references, and explicit practice for
  every numbered section. The nine interactive examples supplement it.
- Retain human review of drafted academic questions and voluntary real-use
  evaluation as separate work; structural coverage is not learning validation.

- Curated CS notes and private progress tracking are complete. Validate the
  review cadence from real local study use before evolving the heuristic.

## Next milestone — accessible interactive expansion

- Completed: the no-motion path respects user motion preferences while direct
  step controls retain every state and explanation.
- Completed: semantic text-table primitives render binary-search intervals,
  linked rewiring, stack/queue state, tree returns, graph frontiers, and DP
  dependencies.
- Prefer learner prediction, constrained input, and feedback over decorative
  animation. Any manipulation must have an equivalent keyboard path.
- Validate designs using private, opt-in transfer prompts and invariant
  explanations; activity, elapsed time, and completion remain insufficient
  evidence of mastery.
- Extend the same validated strategy fields to each future block; add bridge
  cards only when their extra assumption can be stated concisely.
- Validate the private review-queue heuristic only after voluntary real local
  use; research and synthetic events do not establish usability.

## Success Criteria

- A refreshable catalog renders every synchronized official topic and supports focused offline study.
- The nine foundation blocks make invariant, state change, cost, and
  transfer practice explicit without importing external instructional content
  or exposing learner data.
- Future visual additions remain accessible without motion, text-equivalent,
  local-first, and independently testable.
